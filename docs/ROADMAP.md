# 로드맵

각 단계 끝에 "기존 앱 하나를 지울 수 있는가"를 완료 기준으로 삼는다.
버전 번호 규칙은 [RELEASING.md](RELEASING.md) 참고 — 아래 각 단계가 MINOR 버전 하나에 대응한다.

## 0.1.0 — 뼈대 + 창 분할 (Spectacle 졸업)
- [ ] Xcode 앱 프로젝트 + 메뉴바 앱, 설정 창, 로그인 시 실행
- [ ] PolyMacCore: ModuleRegistry, HotkeyCenter(충돌 감지), PermissionCenter
- [ ] WindowModule: ½·⅓·⅔·¼, 최대화, 가운데, 다음 디스플레이, 되돌리기
- [ ] Spectacle 기본 단축키 프리셋 (이주 비용 0)

## 0.2.0 — 캡처·핀·마크업 (Snipaste 졸업)
- [ ] 멀티 모니터 영역 선택 오버레이, 창 자동 감지, 돋보기, 색상 추출
- [ ] 핀: 확대/축소, 투명도, 클릭 통과, 모든 Space 표시
- [ ] 마크업: 사각형·화살표·펜·텍스트·모자이크·번호 스탬프, **벡터 레이어로 재편집**
- [ ] 저장/복사/드래그로 내보내기, 최근 캡처 기록

## 0.3.0 — OCR 자동화 (TRex 졸업)

- [ ] 줄바꿈 정리 / 공백 보존 / 언어 우선순위 / 사용자 단어장
- [ ] QR·바코드, URL 감지
- [ ] 핀 위 라이브 텍스트 선택
- [ ] macOS 26+: 표 인식 → TSV/Markdown
- [ ] Shortcuts 앱 액션, `polymac://ocr` URL 스킴
- [ ] 한글 OCR 정확도 샘플셋 + 측정 스크립트

## 0.4.0 — 클립보드 히스토리 (Maccy 졸업)

- [ ] Concealed/Transient 타입 무시, 앱별 제외, 일시정지
